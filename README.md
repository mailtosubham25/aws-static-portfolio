# AWS Static Portfolio Website

## Overview

This project is a responsive portfolio website built using HTML and CSS and hosted on Amazon S3 Static Website Hosting.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Amazon S3

## Features

- Responsive portfolio
- About Me section
- Technical Skills
- AWS Projects
- Certifications
- Contact section
- Profile image

## Live Website

http://shubham-mandal-portfolio-2026.s3-website.ap-south-1.amazonaws.com
